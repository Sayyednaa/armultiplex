# AR Multiplex Enterprises (armultiplex)

> High-performance 3D responsive website and Progressive Web Application (PWA) for **AR Multiplex Enterprises** — Mumbai's premier metal fabrication workshop specializing in commercial SS kitchens, structural steel sheds, architectural gates, precision sheet metal, and TIG/argon welding.

## 🌟 Features

- **3D Interactive Showcase**: Smooth CSS 3D transforms, real-time gyro/mouse perspective tilt, and interactive flip cards.
- **Progressive Web App (PWA)**: Installable on mobile & desktop, offline support with Service Worker caching (`sw.js`), custom icons, and web app manifest.
- **Mobile-Optimized Experience**: Fixed bottom action dock, responsive touch-friendly UI, and frictionless direct contact buttons (WhatsApp & Phone).
- **Interactive Portfolio & Filter**: Dynamic category filtering for fabrication projects with custom lightbox previews.
- **Custom Contractor Profile**: Interactive 3D card for Proprietor **Abdul Rahman** with a detailed modal profile.
- **Instant Quotation Estimator**: Built-in client quote calculator with automated WhatsApp message generation.

## 🚀 Live Demo & Hosting

This project is built with vanilla HTML5, CSS3, and JavaScript, optimized for hosting on **GitHub Pages**.

To enable GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` and root folder `/`.
3. Click **Save**.
